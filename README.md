我們建造這個網站的原因是因為我們了解到在澳門有許多迷茫，沒有明確目標的學生，他們往往因為缺乏發現自己的能力的機會而最後埋沒了自己的才華。除此之外，老師和家長也能透過這個網站，為孩子們提供一些意見。我們希望那些迷茫當中探索的中學生能夠發現自己感興趣的領域並朝著那個方向前進。

網站設計特色
1. Light / Dark 主題的切換
我們明白到每位使用者都有不同的閱讀習慣，而長期使用螢幕對眼睛帶來的傷害非常高，因此設了Light / Dark 主題模式，讓不喜歡直面白色強光的用戶能夠以一種對眼睛更合適的方式去瀏覽網站，又或者單純因自己的個人審美而選擇。
2. 選擇符合自己的技能方向
透過把生產力中心舉辦的7大賽事分類成四種不同類別的的比賽。此舉能讓使用者按照自己的強項去分析自己適合哪種類型的比賽，從而再深入了解自己是否真的合適這個比賽
3. 比賽資料以及手機網站歷屆回顧獨立敘事
在全澳中學生手機網站技術技能比賽加入了歷屆回顧，使用者可以透過選擇不同的屆次來去瞭解到每一年的手機網站技術技能比賽學生要應對的不同挑戰，並且也可以得知生產力中心每年也會順應住科技發展的趨勢來去設計每一年的比賽要求。
4.響應式設計
我們考慮不是每一位使用者都能夠在電腦瀏覽本網站，因此我們的網站的優先考慮對像是手機用戶，為了支援不同尺寸設備的用戶，網站能夠因應使用者使用的設備大小來調整網站畫面大小，讓每位使用者都能夠使用的途中得到舒適的體驗。
5.無障礙設計
為了讓有特殊需要的使用者也能夠使用我們的網站，我們的網站按照了無障礙網頁規範的四大原則去設計網站，務求讓每一位用戶也能夠使用我們的網站。
6.比賽對比功能
在每一個比賽欄位我們都加入了"加入比較"的按鈕，目的就是希望使用者在遇到不知道自己合適哪個比賽的情況下進行對比，從而選擇出合適自己的比賽
7. 網站首頁
為了慶祝生產力中心成立30周年，我們的網站在首頁介紹了中心的發展點滴
